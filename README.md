# CableDrop

CableDrop is a macOS desktop application that makes transferring files between a Mac and an Android device simple. It provides a clean graphical interface for Android Debug Bridge (ADB), so users can manage file transfers without typing terminal commands.

## Features

- Connect Android devices using USB debugging.
- Detect connected devices.
- Transfer files between Mac and Android.
- Simple, user-friendly interface.
- Guided instructions for connecting devices.
- Built with ADB for reliable file transfers.

## Tech Stack

- **Electron**
- **React**
- **Node.js**
- **Android Debug Bridge (ADB)**

## Requirements

- macOS
- An Android device
- USB cable
- USB debugging enabled on the Android device
- ADB installed or bundled with the application

## Getting Started

1. Clone the repository.
2. Install the project dependencies.
3. Connect your Android device using USB.
4. Enable USB debugging and authorize your Mac.
5. Launch CableDrop and start transferring files.
